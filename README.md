# JASA-OS

Escritorio retro de 8 bits con mis juegos: https://jasa018.github.io

| Juego | Repositorio |
| --- | --- |
| Tierras Partidas: roguelike por turnos | [tierras-partidas](https://github.com/Jasa018/tierras-partidas) |
| Crónicas de Brumaria: RPG de casillas en tiempo real | [brumaria](https://github.com/Jasa018/brumaria) |

Para añadir un juego nuevo, agrega una entrada a `GAMES` en `index.html` (y, si quieres, un icono nuevo en `ICONS`). Todo está en ese único archivo, sin dependencias.
